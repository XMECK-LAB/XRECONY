# XRECONY — Public Publication Structure

**XRECONY — Reconstruction Intelligence for Readable Data Estates**

## Public surfaces

### `main`

The primary discovery/product/documentation surface.

Users should be able to understand the product and reach the current installer directly from `main`.

### `release/1.x`

Historical XRECONY 1.0 Engineering Preview line.

### `release/2.x`

Current XRECONY 2.0 Public Preview line with version-specific documentation and release links.

### `v2.0.0`

Exact release marker.

### GitHub Release `v2.0.0`

Binary distribution authority for the Windows installer, full public package, SHA-256, provenance, SBOM and source manifest.

## Public claim discipline

Published capability, measured evidence, unavailable capability and research objective remain explicitly separated.

The current release does not claim:

- deleted-file recovery;
- damaged-media repair;
- destructive duplicate removal;
- universal benchmark leadership;
- the long-term 25 TB-class research objective as a proven capability.
