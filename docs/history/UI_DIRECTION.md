# XRECONY Public Surface Direction

## Product feeling

XRECONY should feel like a serious reconstruction instrument, not a browser dashboard and not a science-fiction decoration. The interface uses disciplined geometry, live system telemetry and a clear workspace hierarchy.

## Primary screens

1. Reconstruct — select source, workspace and run mode.
2. Explore — search the reconstructed data.
3. History — compare and restore structural generations.
4. Verify — inspect and download the reconstruction receipt.
5. Speed — inspect measured performance.
6. Intelligence — review metadata patterns and storage signals.
7. Map — explore structural layers, sources and activity.

## Visual rules

- White is the working surface.
- Navy is the system surface.
- Blue/cyan communicates live structure.
- Orange is reserved for decisive actions and changes.
- Motion must reflect actual engine state.
- Internal research vocabulary stays in project documentation and machine evidence, not in the everyday public workflow.
- The public experience uses plain, confident language.

## Core boundary

This edition does not change reconstruction behavior. Future UI iterations branch from this surface package while the V4.5.1 core remains frozen.
