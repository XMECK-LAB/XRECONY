## Understand your data before you move it

XRECONY reconstructs readable data estates into a separate, evidence-backed structural workspace so you can understand what exists, how it relates, what changed, where duplicate or version candidates may exist, and what can be safely copied elsewhere.

> **The source remains the source.**

```text
SOURCE ≠ WORKSPACE ≠ REALIZATION DESTINATION
```

## XRECONY 2.0 capabilities

- Local folders
- Mounted HDD / SSD
- Mounted SMB / NAS
- Portable metadata manifests
- Structural Twin reconstruction
- Source / Type / Timeline / Recovery views
- Structural relationships
- Duplicate candidates
- Version-family candidates
- Generation comparison
- Drift detection
- Evidence and report exports
- Reconstruction Intelligence
- Copy-first Safe Realization to a separate destination
- Native Windows desktop application

## Product boundary

XRECONY 2.0 is a **Public Preview**.

It is not presented as:

- a backup or snapshot replacement;
- deleted-file recovery;
- damaged-media repair;
- a destructive duplicate remover;
- a universal performance benchmark claim.

Native public cloud-provider support and the long-term 25 TB-class objective remain outside current public claims.
